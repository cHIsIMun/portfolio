# portfolio

🇧🇷 Português | 🇺🇸 [English](README.en.md)

> Portfólio pessoal de página única em HTML, CSS e JavaScript vanilla.

## Visão geral

Site de **portfólio pessoal** de uma página (Home, Sobre, Projetos, Contato), com navegação por *scroll* suave e links para redes sociais. Construído sem frameworks.

## Stack

HTML · CSS · JavaScript vanilla.

## Como executar

Abra `index.html` no navegador.

## Estado do projeto

Estrutura estática funcional; seções de conteúdo (Sobre, Projetos, Contato) ainda a preencher.
